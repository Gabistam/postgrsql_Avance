6.1Les recordmen

Trouvez le record de chaque jeu, puis le ou les joueurs qui l'ont réalisé. Procédez en deux étapes avec une CTE.

WITH records AS (
    SELECT jeu, MAX(score) AS record       -- étape 1 : le record de chaque jeu
    FROM parties
    GROUP BY jeu
)

FROM parties p

✅ Corrigé
SQL

    SELECT id, nom, parent_id, 0 AS distance
    FROM genres
    WHERE nom = 'Drill'
    UNION ALL
    SELECT g.id, g.nom, g.parent_id, a.distance + 1

7.3Taille des familles

Pour chaque genre racine, comptez le nombre total de sous-genres, tous niveaux confondus.

💡 Indice

▶ Résultat attendu 3 lignes

Rock4
Électro3
Hip-hop2
✅ Corrigé
SQL
WITH RECURSIVE arbre AS (
    SELECT id, id AS racine_id              -- chaque racine est sa propre racine
    FROM genres
    WHERE parent_id IS NULL
    UNION ALL
    SELECT g.id, a.racine_id                -- les descendants héritent de la racine
    FROM genres g
    JOIN arbre a ON g.parent_id = a.id
)
SELECT r.nom AS racine, COUNT(*) - 1 AS nb_sous_genres   -- -1 : on ne compte pas la racine
FROM arbre a
JOIN genres r ON r.id = a.racine_id
GROUP BY r.nom
ORDER BY nb_sous_genres DESC;

9.2Les mois en baisse

Listez les mois où un artiste a fait moins d'écoutes que le mois précédent.

💡 Indice

▶ Résultat attendu 3 lignes
artistemoisprecedentecoutes
Kairo2026-041300012500
Nova2026-031500014000
Nova2026-063000028000
✅ Corrigé
SQL
WITH evolution AS (
    SELECT artiste, mois, ecoutes,
           LAG(ecoutes) OVER (PARTITION BY artiste ORDER BY mois) AS precedent
    FROM streams
)
SELECT artiste, TO_CHAR(mois, 'YYYY-MM') AS mois, precedent, ecoutes
FROM evolution
WHERE ecoutes < precedent
ORDER BY artiste, mois;

🎬Projet fil rouge · FilmBox
FilmBox est un réseau social de cinéphiles, sur le modèle de Letterboxd : les membres notent les films qu'ils voient, tiennent un journal de visionnage et créent des listes. Vous êtes la personne chargée de sa couche données. À vous de répondre aux besoins de l'équipe produit, mission après mission.

🗄 La base

30 films et leurs castings réels, 3 sagas, 72 personnes, 8 membres fictifs, leurs notes et leur journal de visionnage.

Schéma
sagas        (id, nom)
films        (id, titre, annee, genre, saga_id, film_precedent_id)
personnes    (id, nom)
casting      (film_id, personne_id, role)          -- role : 'acteur' ou 'realisateur'
utilisateurs (id, pseudo, ville, inscrit_le)
notes        (utilisateur_id, film_id, note, note_le)   -- note de 0,5 à 5
journal      (id, utilisateur_id, film_id, date_visionnage)
